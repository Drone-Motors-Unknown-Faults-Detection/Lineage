## 最小重現與範圍

建立兩個同大小、同mtime而位元組不同的 fixture CSV，無materialization manifest時呼叫 `experiments.exp6_formal_benchmark.dataset_fingerprint()`；現行 size/mtime 不能保證內容有差異就不同。檢查 `core/formal_data.py` manifest 的絕對路徑；核對 exp1–3/formal 每次輸出缺少的 Python/OS/packages/commit與來源資訊。

範圍：`core/formal_data.py`、`core/logger.py`／共用 metadata、exp1–3/formal 入口與相關 schema/手冊。先定義內容雜湊、資料版本、sample來源、private sidecar；公共摘要不含 username／絕對路徑／secrets。參數解析與模型邏輯不改。
