# 核心示範腳本

條件：formal105，T1/8000rpm，seed42，Maha–LW、q95；研究對照kNN使用相同來源。先看[實驗總覽](實驗總覽.md)，實際案例與截圖在[交付報告](../../reports/navigation_20261007/final_report.md)。

## 接著用一分鐘對照研究

LW回答距離估計與校準是否穩定；早期18神經模型文件不是現在formal105成績。75維在固定跨motor配置known accuracy增加4.52百分點，但T1 unknown仍0%。跨motor三用途分開修正selector/cal依賴；全部資料歷史曝光、raw/session未知，仍不能宣稱新盲測可靠。

exp2回答群組確認與完整池更新；arrival-only另有策略研究，不能混成此展示已完成。趨勢回答劇本警報。PolarMap回答幾何呈現。稽核回答來源、切分、曝光哪部分可證實，不改未知欄位為PASS。

## 復原與失敗備案

暫停不換抽樣器；重設會明確重擬合並清隔離區、保留舊epoch紀錄。換motor/RPM先檢查再明確重建，不能沿用原模型。最後一個瀏覽器斷線停止tick，重連保留模型且不自動播放；建模／確認重任務不因斷線強行取消。
